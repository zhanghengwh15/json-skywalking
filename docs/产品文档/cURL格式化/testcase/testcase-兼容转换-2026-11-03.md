## 执行记录与限制

- `npm run test:curl`：14 组通过；包含实际 `/bin/sh` 参数捕获。
- 用户原始附件离线解析：成功识别 POST、12 个显式请求头、5829 字节内联正文；未执行真实命令，未保存真实凭据。
- `npm run build`：vue-tsc 与 Vite 通过。
- Ego 浏览器：示例、两种正文模式、多行切换、JSON 补头开关、Ctrl + Enter、复制反馈、旧输出失效、错误提示均通过。通过截图检查双栏布局。
- 页面验证发现并修复：示例填入后，异步输入监听会清空刚生成的结果；改为同步使旧结果失效，再执行转换。
- 用户 Linux / cURL 7.29 真机、目标 API、Tauri WebView 和 Windows 尚未执行验证；不以本机 Shell 测试代替这些结果。
