# Tauri App

## 开发工具集合

这是一个基于 Tauri 的桌面应用程序，提供多种开发辅助工具，包括 JSON 解析、HTTP 请求解析、SQL 解析等功能。

### 🚀 主要功能

#### JSON 解析功能
- **智能格式识别**：自动识别并解析多种 JSON 格式
- **语法高亮**：专业的 JSON 语法高亮显示
- **格式化/压缩**：支持 JSON 数据的格式化和压缩
- **错误提示**：精确的 JSON 语法错误定位和提示
- **暗色主题**：支持明暗两种主题模式切换
- **一键复制**：快速复制格式化后的结果

#### HTTP 解析功能
- **GET 请求解析**：自动解析 URL 和查询参数
- **POST 请求解析**：支持 JSON 数据验证和格式化
- **cURL 生成**：自动生成标准 cURL 命令
- **请求测试**：直接在应用内测试 HTTP 请求
- **格式化显示**：支持 cURL 命令格式化和压缩
- **暗色主题**：适配深色模式，减少视觉疲劳

#### SQL 解析功能 ✨
- **SQL 格式化**：智能格式化 SQL 语句
- **语法高亮**：SQL 关键字和函数高亮显示
- **多种方言**：支持多种数据库方言
- **错误检测**：SQL 语法错误智能检测
- **暗色主题**：与其他工具保持一致的深色体验

#### 历史记录功能
- **自动保存**：解析成功的请求自动保存到历史记录
- **智能搜索**：支持按 URL、请求类型、标题等搜索
- **批量操作**：支持批量选择和删除历史记录
- **快速加载**：点击历史记录快速加载到编辑器
- **数据导出**：支持历史记录导出为 JSON 格式
- **统计信息**：显示总计、分类统计、今日记录数等

### 📖 使用方法

#### JSON 解析
```json
{
  "name": "示例数据",
  "items": [1, 2, 3],
  "config": {
    "enabled": true
  }
}
```

#### HTTP 请求
```
// GET 请求
http://api.example.com/users?page=1&size=10

// POST 请求
POST http://api.example.com/users
Content-Type: application/json

{
  "name": "张三",
  "email": "zhangsan@example.com"
}
```

#### SQL 格式化
```sql
SELECT u.name, d.department_name FROM users u LEFT JOIN departments d ON u.dept_id = d.id WHERE u.status = 1 ORDER BY u.create_time DESC;
```
