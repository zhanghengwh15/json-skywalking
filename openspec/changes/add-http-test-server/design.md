## Context

现有 Axum 服务固定占用 127.0.0.1:8765；不存在通用日志页面。新增服务由桌面 IPC 管理，使用独立端口，与现有业务隔离。

## Goals / Non-Goals

**Goals:** 本地可配置端口和多 URL、任意请求参数、自定义原文响应、独立请求日志、cURL 快速生成、MD 预览及导出。

**Non-Goals:** 不新增 CLI 子命令、远程管理 API、SQLite 表、局域网监听、动态脚本或生产网关。

## Decisions

- 新增 `http_test_server`，以 Tokio 异步互斥锁串行启动/停止，以独立有界队列保存日志，避免请求等待服务生命周期锁。
- 采用 fallback 内精确匹配方法和路径，避免把用户 URL 当作 Axum 路由表达式导致 panic；ANY 与具体方法同路径不允许重叠。查询参数不影响匹配。
- 默认 8766，限定 1024–65535、排除 8765；先成功绑定再更新配置，端口占用明确报错。应用重启后不自动监听。
- 每个接口的 `responseBody` 为不超过 64 KiB 的 UTF-8 原文，允许 JSON、文本、HTML、XML、空内容及不合法 JSON，不做解析、格式化或业务包装。默认仍为 code=0、message=ok、data=null 的 JSON 示例。
- 新增 `contentType` 字符串，默认 `application/json; charset=utf-8`，旧配置缺省时由 Serde 补齐；必须为 1–256 个可打印 ASCII 字符且不能全为空格。仅匹配的接口响应使用此头，系统错误和预检保留原有 JSON 类型。配置仍在停止后编辑、成功启动后保存；HEAD、204、205、304 无正文。
- 接收原始 body，不对 JSON、表单或文本做业务校验；限制 1 MiB，日志最多保留 200 条、每条正文 64 KiB。未匹配 404、预检 OPTIONS 204、超限 413 也记日志。
- 配置存入应用数据目录 `http-test-server.json`；日志仅在内存保留，跨页面和服务重启保留，退出应用清除。敏感请求头脱敏，不写入通用文件日志。
- Vue 新增测试服务和请求日志两个路由；日志页面每秒刷新并在离开时释放计时器。浏览器预览明确提示需要 Tauri。
- Markdown 由当前配置生成；桌面 command 将内容写入系统下载目录中唯一命名的 MD 文件，返回保存位置，不新增文件系统插件权限。
- 页面和 Markdown 共用 `testEndpointCurl` 生成兼容 cURL 7.29 的命令，ANY 示例使用 POST，HEAD 使用 `--head`；通过 POSIX 单引号保护 URL。接口内按钮打开只读命令框，复制使用既有浏览器剪贴板 API，失败提示手动复制。⌘ / Ctrl + Alt + C 生成最近聚焦或点击接口的命令，默认第一个；监听仅在页面挂载期间有效，忽略重复按键与输入法组合状态，不自动执行请求。
- 页面作用域内使用统一高度的控件、自绘下拉箭头及折叠入口，保留原生 select 和 details 的键盘语义，窄屏允许配置行换行。
- HTTP、IPC 字段与使用示例统一维护于 `docs/http-test-server-对接文档.md`。CLI 和旧 HTTP 入口保持原契约。

## Risks / Trade-offs

- [日志可能包含测试数据] → 请求头常见凭据脱敏；正文仅在专用内存日志页显示，不写磁盘；界面注明保存范围与截断。
- [内存与流量] → 有界日志、请求大小和读取超时；停止等待有上限，必要时终止监听任务。
- [跨平台导出] → 使用 Tauri 下载目录解析和 Rust 文件写入，测试分别记录平台；未做 Windows 实机验收。

## Migration Plan

不升级数据库或依赖。构建安装后从测试服务页面手动启动。回退旧版仅忽略新增配置文件；现有业务数据不受影响。发布与验证结果在需求目录中维护。

2026-11-06 增量兼容：本版本自动补齐旧配置的 `contentType`；回退到仅允许 JSON 的旧实现时，非 JSON 或空正文配置会被判为非法并回退默认值。需要保留自定义配置时先备份，或在回退前将响应体恢复为合法 JSON；旧实现忽略新增的 `contentType` 字段。

实施补充：`http-body-util` 使用现有锁定版本作为直接依赖，以类型判断正文超限；Tokio 显式启用网络、计时和 I/O 特性。发布配置、权限、回退及真实验证范围见 `docs/产品文档/HTTP测试服务/deploy/发布说明-HTTP测试服务.md`。
