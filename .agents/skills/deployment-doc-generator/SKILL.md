# Dev Tools 发布文档

先读 `AGENTS.md` 和 `.codex/rules/common/docs-prd.md`，读取当前 PRD / LLD 与实际受影响的构建、安装和数据库实现。

## 核实与产物

- 从 `package.json`、`Cargo.toml`、Tauri 配置和安装脚本核实实际命令、二进制与目标平台；不要自行统一目前不同的版本字段。
- 安装和 PATH 行为优先引用 `docs/dev-tools-cli-安装与PATH.md`；核实后增量更新该文档。
- 变更涉及 SQLite 时，从真实 schema 和初始化代码确认升级方式、事务和兼容性，不套用 MySQL 脚本。
- 写入 `docs/产品文档/{需求}/deploy/发布说明-{需求}.md`；确有独立 SQL 资产时放同级 `sql/`，否则说明升级由何处代码执行，不额外造脚本。

## 说明内容

1. 发布范围、PRD / 设计关联、目标平台与版本来源。
2. 前置条件、实际构建命令、产物位置与安装步骤。
3. 应用数据目录、升级前备份要求与升级行为；涉及 WAL 时说明一致性备份方法和停写条件。
4. Tauri capability、插件、端口或配置变更，以及组件发布顺序。
5. 安装后检查：启动、健康接口、受影响 UI / IPC / HTTP / CLI，按实际范围选择。
6. 回退：旧版本兼容性、数据恢复、不可逆操作与适用条件。
7. 实际验证平台、结果、未测项及执行记录。

Windows 区分 GUI 与 console 二进制，说明 stdout；macOS 安装路径与 Windows 分开。不要把一次本机成功写成跨平台验证通过。

生成操作示例与实际执行分开。执行只在用户授权的目标和影响范围内进行；文档任务不操作真实数据库、安装程序或外部发布目标。更新 MOC，并将已确认脚本、配置与执行顺序同步回设计摘要。
